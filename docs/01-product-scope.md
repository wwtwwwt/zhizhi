# 01 · 产品与范围

## 定位

枝知（Learnhelper）是帮助成人自主学习者理解内容、补齐背景并延伸探索的 LLM 对话工具。用户可以从一个问题开始，也可导入 Markdown 或论文，再围绕具体文字建立持久分支。

主对话保持阅读主线，分支承载追问或笔记。用户可显式结合某块的后代问答重新解释该块；不会仅凭分支数量或深度推断用户能力，也不自动改写正文。

## 术语

| 术语 | 含义 |
|---|---|
| Session／会话 | 一个主对话流及其全部分支 |
| Stream／对话流 | 按顺序排列的用户与 AI 消息，主流和分支共用交互 |
| Message／消息 | 一次用户输入、导入文档、笔记或 AI 回复，可包含多个块 |
| Block slot／块位置 | 消息内独立的 Markdown 块位置，维护顺序和当前版本 |
| Node／内容节点 | 一个块的独立版本；正文定稿后不可覆盖 |
| Anchor／高亮 | 某版本正文中的唯一选区，关联唯一分支 |
| Question／追问分支 | 保存问题并启动 AI 回复的子对话流 |
| Note／笔记分支 | 先保存用户笔记，不自动调用模型，之后可继续问 AI |
| Rewrite／重新解释 | 读取目标版本及其可见后代问答，产生候选新版本 |

Markdown 标题层级、版本关系与分支层级互相独立。上下文中的 root 指会话的主对话流。

## 核心流程

1. 提问获得流式解释，或导入文档建立主流首条消息。
2. 在一个已定稿块内选择文字，通过浮动工具条或右键菜单追问／记笔记。
3. 提交追问后打开分支弹窗；保存笔记后收起编辑浮层，点击高亮再打开分支。
4. 分支内可继续普通对话，也可选中文字建立更深分支。
5. 关闭窗口返回上一层，点击高亮或右栏预览重开已保存分支。
6. 有分支的非图片块可主动重新解释，预览后采用新版或保留原文。
7. 版本独立保存和切换，分支只显示在其来源版本中。

## 当前能力

- 会话管理、流式 Markdown／公式、图片展示、消息定位和持久恢复。
- 用户与 AI 定稿消息共用分块、选区、编辑、插块、版本及删除操作；非图片块有分支即可重新解释，包括导入文档中的文字块。
- 递归追问、笔记、原文高亮及分支摘要；祖先路径上下文冻结。
- 多模型管理、OpenAI Chat Completions 兼容接入、固定模拟模型、图文附件、思考摘要展示。
- Markdown 文件与 InkToMd 论文链接导入。
- 两栏设置、通用偏好、本地数据统计与全量清除。

## 边界

当前为Electron桌面应用，内部自带Node／Express和SQLite，保留本地Web开发预览。已生成并验证macOS arm64本地包；其他平台构建配置已准备但未验证，正式签名和发布后续处理。纯静态网页版与PWA未实现。

不提供课程体系、强制测验、全局知识画像、跨兄弟分支隐式记忆、账号、云同步或多人协作。论文转换属于明确触发的导入，不代表具备通用联网代理能力。

关闭分支弹窗只收起视图，不删除分支或停止生成；关闭应用主窗口则退出应用并中止生成。刷新保留已保存内容，不恢复完整弹窗栈、输入草稿或已断开的流式连接。

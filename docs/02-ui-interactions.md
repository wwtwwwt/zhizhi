# 02 · UI 与交互

## 布局与共用能力

默认近白底、中性灰和紧凑间距，正文默认15px，UI保留原有紧凑字号，列表与正文采用更深文字颜色，正文呈连续文章排版。左侧栏依次是“新的对话”、文件夹、最近对话，底部只保留设置入口；logo下显示ZHI ZHI，新对话按钮不带右侧箭头。文件夹最多两级，可拖放管理和排序；最近对话固定按更新时间倒序，不能拖动排序。文件夹区超过列表可用高度50%后独立滚动，采用淡色细滚动条，详见[14](14-session-folders.md)。主区为会话标题、对话流和输入框，无常驻模型状态灯。

主流与所有分支共用 Conversation、MessageView、BlockView 和 SendComposer。每条消息预留右侧功能区，不绘制正文与右栏之间的分割线，输入框只与正文等宽，不伸入右栏。用户头像显示昵称的首个字素；AI 使用小圆形图标，笔记首条消息使用笔记图标，导入文档使用固定文档图标，旁边显示文件名。

每个流左侧有消息定位竖条，默认淡色，悬停／聚焦加深并显示消息开头预览，底部渐隐；离开即消失。点击定位对应消息。

右栏分支卡片以两行显示首条问题／笔记和首条 AI 回答摘要，读取当前可见内容；点击恢复分支，悬停与原文高亮联动。追问使用蓝色，笔记使用黄色。密集卡片避让，不在正文段落之间插入工具占位。

## Markdown、公式和流式输出

| 内容 | 块粒度 |
|---|---|
| 标题、段落 | 每个一个块 |
| 列表 | 递归拆项，保留编号和缩进 |
| 引用 | 按内部内容拆分，保留引用排版 |
| 围栏代码、表格、块级公式 | 各自完整成块 |
| 图片 | 独立图片块 |
| 分隔线 | 展示，不创建文字分支 |

行内格式和行内公式不独立拆块。使用共享 AST 解析，支持 `**注意：**LLM...` 等标点后紧接字母／数字的加粗；代码、转义和公式保留各自语义。原始 HTML 按安全标签白名单解析为共享 AST，支持表格（含表头、合并单元格）、上／下标、常用行内格式、链接和图片；不执行脚本，不保留事件属性、任意样式或嵌入内容。代码中的 HTML 仍作为代码展示。

流式期间约45ms合并 Markdown 更新，与定稿共用 splitMarkdown 切块规则及块样式；列表逐项使用相同的编号／圆点、嵌套缩进和段落间距，引用也复用块布局，避免定稿时列表间距跳变。稳定块复用、新文字淡入，不显示末尾闪烁光标。生成中的草稿不能建立分支；手动停止后已有正文立即切块，正常支持编辑和追问并进入后续上下文，保留“已停止生成”提示且不重复显示原始草稿；完成时静态块与流式草稿一次切换，避免重复正文闪烁。

公式用 KaTeX 渲染，行内 `$...$`、独立行 `$$...$$`。点击选中整式，选区跨公式时扩展至整式并标示背景。公式浮动菜单提供复制、追问和笔记；复制返回带定界符的 LaTeX。

## 选择、复制与分支

单块非空选区显示追问／笔记／复制工具条。mouseup 检查真实 Range，不要求鼠标松开位置仍在块内。正文未定稿、对话正在生成、选区跨块或覆盖已有高亮时不能新建分支。

每个文字位置最多属于一段高亮，一段高亮只有一个分支；相邻允许，部分和完全重叠均拒绝。以节点 ID 和偏移判断，重复字符串不会误配。跨行内格式的多个视觉高亮仍属于同一分支。点击高亮重开原分支。

复制优先返回 Markdown：完整选中的块返回该块 raw Markdown；部分块映射到源码边界后截断，不补齐格式；跨块以空行连接。编辑输入框保留原生复制。

追问和笔记共用小悬浮编辑框。追问底部有附件、上下文环、模型选择和发送；笔记底部仅取消／保存笔记，Enter 换行。提交前不创建分支；取消不落库。笔记保存时原子创建首条消息，不调用模型，之后打开分支可继续问 AI。

## 块手柄和右键菜单

悬停／键盘聚焦显示左侧六点手柄，不压暗整块。有多个可用版本时，手柄左侧额外显示同尺寸历史图标，点击展开同一菜单。

手柄菜单包含版本切换、结合追问重新解释、在下方添加块、编辑、整块复制和删除。版本与重新解释均不占右栏。编辑原地进行；保存时第一块成为原槽新版本，其余拆分块完全独立。添加块直接进入编辑，取消不留空块。

正文右键菜单按选区分组：

1. 单块分为五组：追问／笔记；历史版本（有版本时）；结合追问重新回答（有分支时）／在下方添加块／编辑内容；复制块／复制整条消息；删除块／删除整条消息。没有历史版本时不显示该组及多余分隔线；历史版本行不绘制底边框，统一由组间分隔线分隔。无效追问动作灰显，点击用toast解释原因。选择范围覆盖已有追问／笔记高亮时静默关闭浮窗，不主动弹toast；仅点击右键菜单灰色追问／笔记项时提示选区冲突。块复制始终复制当前块源码，跨块复制仍复制选区。
2. 高亮处：第一组在追问／笔记下方额外显示删除分支，与这两个按钮共组；删除块和删除整条消息仍在末组。
3. 对话流最新一条消息为 AI 且上一条为用户时，该 AI 块的右键删除组末尾提供「删除整条消息并重新提问」。删除本轮两条消息及相关分支，将用户当前可见正文和原附件恢复到对应输入框；正文置于已有草稿之前，附件合并保留。操作沿用删除确认偏好，后端重新校验最新消息和流空闲状态。
4. 跨块选区：只显示 Copy 图标和「复制为 Markdown」。

有历史版本时，删除块使用二级菜单：删除当前版本、删除所有版本，分别带垃圾桶和多文件图标；每项沿用删除二次确认偏好。二级菜单支持悬停、点击与左右方向键，并适配视口边缘。整消息复制拼接当前可见块（含列表／引用标记），删除确认文案为「删除整条消息？消息内的分支也将删除」，其余消息保留。

输入框保留原生右键菜单。菜单支持视口边缘约束、Esc、方向键、外部点击和滚动关闭；切版后需重新选择文字。

## 窗口与生成生命周期

分支窗口保持居中，支持向上／向左错位堆叠；最近三层可见，下层 inert，只允许顶层交互。开合使用轻量位移、缩放和淡入淡出，遵循系统减少动态效果偏好。

Esc、关闭按钮、窗口外部点击关闭顶层；路径可返回主流或祖先。关闭保留分支数据，生成任务独立于窗口，继续在后台运行；显式停止才结束生成。返回保留页面生命周期内的草稿、阅读位置并恢复来源附近焦点。

四角均可拖拽／方向键缩放，常规视口最小高度220px（原300px），窗口可拉高至视口高度减35px，上下各预留17.5px；窗口不能移动位置；默认仅压暗背景，通用设置可启用背景模糊。仅下方两角显示 L 形提示。分支与 WindowPanel 管理窗口共用同一尺寸，实时联动，localStorage 记忆；小视口只临时约束尺寸。详见[设置与数据管理](10-settings-and-data.md)。

## 重构、版本与删除

非图片块有分支时可结合追问重新解释，在原块处展示候选；可停止、采用新版或保留原文。候选不可追问。AI 重构完成后按相同Markdown规则切块预览；采用时仅第一块是原槽新版本，其余作为独立新块插入下方，不随第一块切版或删除。拒绝预览不插入新块。

版本切换只展示对应节点的正文、高亮和分支。拒绝的候选不出现在版本列表，旧版分支不会复制到新版。

多版本块的菜单直接选择删除当前版本／删除所有版本，二次确认只负责确认。当前版本删除后优先切前一版本，否则后一版本；单版本删除整块。确认文案：

| 操作 | 提示 |
|---|---|
| 单块 | 删除此块？块内的分支也将被同时删除 |
| 分支 | 删除此分支？其子分支也将被同时删除 |
| 当前版本 | 删除当前版本？此版本的分支也将删除 |
| 所有版本 | 删除所有版本？块内的分支也将删除 |

删除递归回收对应分支树及无用资源，取消不改变数据。通用设置可关闭常规删除二次确认；清除所有数据始终单独确认。

视觉验收由用户完成；自动化只检查行为、数据、焦点、滚动及布局约束，不截图。

正文滚动由通用设置autoScroll控制，默认开启；主流和分支共用。生成中用户滚轮／触摸滚动会锁定本轮不再跟随，即使回到底部也不恢复；下一轮重新判断。ResizeObserver跟随实际正文高度变化，导入首次仍停在开头。导入文档与AI正文使用相同段落间距，无用户消息的段落压缩覆盖。图片查看器支持直接鼠标滚轮缩放、触摸板双指平移和捏合缩放（Chromium的ctrl+wheel事件），按住左键拖拽平移，重置同时归位，不改变分支或图片上下文规则。

## 空回复与重新编辑

生成停止、失败或断连时，已输出正文按相同规则切块，可编辑、追问并进入后续上下文；完全没有块的消息自动移除，不显示右栏重新编辑按钮。编辑为空、删除最后一个块、生成结束后无块同样移除消息，按引用规则清理资源。生成中的占位消息不清理，仅含思考摘要而无正文块的终态消息也移除。

所有toast从页面顶部居中弹出。停止／失败提示附「重新编辑」动作（普通回复且对应问答仍为最新时）；点击直接删除该AI回答及紧邻的用户消息，将用户正文和原附件恢复到该流输入框，不自动调用模型。若空AI已经移除，则恢复仍在末尾的原用户消息；后端再次检查流空闲及最新位置，避免过期toast误删后续聊天。普通提示4.5秒，有操作的提示15秒；可手动关闭。右键重新提问保留原删除确认偏好。

恢复内容放在已有草稿之前并合并附件，按流隔离，未打开的分支重新打开时消费一次。

重构流式及完成预览共用主对话的Markdown块正文容器，段落间距、字号、行高、列表标记和缩进采用相同规则。首段沿用原列表标记时，生成与完成阶段保持一致。列表／引用样式仅作用于所属块直属正文，不影响嵌套预览；容器隔离首尾外边距，预览卡片的边框、内边距与操作区保留。

共用SendComposer输入区与正文使用同一字体链及字号设置（默认15px），覆盖主对话、分支与追问／笔记浮窗；工具栏继续使用紧凑UI字号。正文常规字重400、正文标题550、Markdown加粗600；输入和UI恢复原有字重（普通文字400，标题按原有500／550／600层级）。最近对话为空时不显示占位文字。

消息定位导航仅为AI消息生成细横条，少于三条AI消息不显示；默认短且淡，不因当前阅读位置加长；鼠标进入区域／键盘聚焦时显现，具体项悬停时延长；数量增多时自动压缩行高，最小3px后滚动；点击跳转至该AI消息。悬停始终显示AI回答预览（底部渐隐）；紧前消息为用户消息时，顶部额外显示一行用户原文，超长省略。侧栏枝知品牌文字不再提供点击操作。

侧栏分界线悬停250ms后显示双三角缩放光标，可拖动调整；支持方向键、Home／End，宽度180–360px且尽量为正文保留480px。localStorage.sidebarWidth自动记忆，缩小视口仅临时约束。折叠后侧栏不可聚焦，展开动画裁切固定宽度内容以避免挤压。消息导航按正文滚动区域垂直居中，条目常规高度10px，数量多时压缩至3px。

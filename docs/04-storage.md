# 04 · SQLite 存储与数据模型

## 当前结构

新库直接执行 `server/schema.sql`；当前结构重启直接打开，不重建已有数据。不提供旧开发数据库升级或兼容回退。

浏览器开发预览默认目录为 `.learnhelper/`，可通过 `LEARNHELPER_DATA_DIR` 覆盖；桌面版使用系统应用数据目录中的zhizhi／zhizhi-development，见[12](12-electron.md)。启用外键、WAL 和 busy_timeout；写入使用短事务，不在事务内等待网络。UUID 不复用，时间使用 UTC ISO 字符串。数据库、WAL／SHM 和 secrets.json 不提交 Git。

## 实体

| 表 | 职责 |
|---|---|
| sessions | 会话标题、创建及更新时间 |
| streams | 主／分支对话流，创建时冻结的祖先节点引用 |
| messages | 消息顺序、角色、状态、原始 Markdown、思考摘要、模型标签及导入文档标识 |
| block_slots | 消息内独立块的位置、当前版本、初始排版和删除标记 |
| content_nodes | 不可变的版本正文、规范选区文本、类型及来源版本 |
| node_layout | 手动编辑版本的排版；初始版本使用槽排版 |
| branches | 源版本、唯一选区、子流、question／note 类型和笔记幂等 ID |
| generations | 任务状态、模型配置快照、上下文快照、流式草稿及错误 |
| rewrite_proposals | 重构候选、源版本与采用／拒绝状态 |
| models | 每个模型的公开配置 JSON，包括图片能力和参数 |
| attachments | 随用户消息主动发送的图片／文本资源 |
| document_resources | 导入文档的展示图片，不进入模型上下文 |
| settings | `preferences` JSON：通用偏好、上次选择模型（页面 localStorage）、模拟速度 |

浏览器预览的模型密钥存 secrets.json 的 `modelKeys[模型内部ID]`；Electron版同文件由safeStorage整体加密（见[12](12-electron.md)），POSIX 权限0600；模型列表只返回是否配置。模型连接统一由 ModelRegistry 管理。

## 块与版本

- 原始版本不可修改正文、选区文本或来源节点；SQL 触发器约束不可变性。切换版本只能指定同槽 available 节点。
- 手动编辑按 Markdown 重新切块：第一块是原槽的新版本，其余是独立槽，各自维护版本及分支，不受原槽切版／删除影响。下方添加同样创建独立槽，排序两阶段腾位以保持唯一约束。
- 读取当前正文统一走 visibleSlots，只过滤块自身删除状态。冻结上下文直接引用不可变节点，不随 active 指针改变。
- 重构完成只产生一个 candidate 节点和 pending proposal；采用时检查预期源版本，再切换 active 指针。拒绝则标 discarded，不出现在可用版本中。重构预览粒度与手动拆块不同。
- 编辑、插块、删除及切版校验 expectedActiveNodeId。编辑／插块／删除要求所在流空闲，编辑／删除还拒绝存在待处理重构的源块；切版验证目标节点所属槽与可用状态。

## 分支与上下文

分支绑定具体版本，选区是该节点 selection_text 的 UTF-16 偏移，需位于完整字素／公式边界。SQL 约束同节点选区不重叠；相邻选区允许。

创建分支、冻结祖先引用、写入首条消息在一个事务完成。追问还创建回复占位及生成任务；笔记必须同时提交非空正文，不调用模型、不需要密钥，不建立空笔记分支。相同请求 ID 幂等重放，冲突请求拒绝。

上下文引用仅有 `role + nodeIds + 可选附件消息ID` 或引用文本 quote。祖先前缀冻结，兄弟分支不互读；普通对话不读取后代，仅显式重构会遍历目标版本的后代问答。

## 删除与资源回收

`DELETE /api/slots/:id` 必须显式传 `scope: all | current`。删除当前版本优先切换前一可用版本，否则后一版本；无剩余版本时删除整块。删除所有版本移除该槽全部版本中的分支树。

独立删除分支先枚举所有版本和已删槽内的后代流，停止相关任务，再删除流；仅删除 branches 行不会反向删除 stream。外键级联回收消息、槽、节点、分支、附件及生成记录，保留父级与兄弟。客户端按返回的 streamIds 清理缓存。

已删节点若仍被其他现存分支冻结引用则保留供上下文读取，否则物理回收；不再被可显示版本引用的文档图片和不再需要的附件同步回收。无回收站。删除会话级联清理整个会话。

全量清除需要单独确认，停止生成，事务清理所有业务数据、模型和偏好，清空密钥，再 checkpoint／VACUUM；保留当前 schema，固定模拟模型始终可用。

## 生成恢复与文本解析

服务重启将残留 queued／streaming 消息和任务标记 interrupted，可显式重试。任务保存 `{ modelConfig }` 快照；重试沿用原模型配置，密钥按该模型 ID 读取当前值。停止／失败保留草稿，不形成可分支节点；失败重构不修改原正文。

Markdown 加粗由共享解析器统一处理：支持中文标点后紧接中文、英文、数字或符号，例如 `**注意：**LLM...`，也支持 `**已经习惯 `checkout`：**继续` 这类包含行内代码、公式或链接的内容。解析修复会保留原始源码偏移，流式和静态渲染、选区复制采用同一规则。

HTML 表格与行内标签通过共享安全 AST 渲染，保留原始源码位置；选择文本不含标签，复制完整块仍返回原始 HTML／Markdown，部分选择映射回源码。表格完整成块，上／下标保持行内；HTML 图片沿用独立图片块及展示资源流程。

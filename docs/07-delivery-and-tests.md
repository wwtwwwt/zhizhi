# 07 · 验证与交付

## 运行与检查

需要Node.js 24.18或更新的24.x及npm，使用内置node:sqlite。

```sh
npm install
npm run dev
npm run build
npm start
npm test
npx playwright install chromium
npm run test:e2e
```

开发Web为127.0.0.1:5173，API为3001。build包含TypeScript检查，start由本机Express提供dist和API。

Vitest使用临时SQLite和本机HTTP stub；Playwright先构建，用`.learnhelper/e2e`和5175启动独立服务，单worker运行。测试不调用付费模型，不使用其他项目密钥。截图断言和trace截图均不启用，界面视觉验收由用户进行。

## 当前基线

2026-10-31功能回归：38项代码／协议测试及5项相关端到端测试通过，包含TypeScript及生产构建、三层分支与重构、模型管理和通用设置。Electron源码入口与实际打包的macOS arm64应用均通过无截图smoke：安全存储、内部API鉴权、模拟流、重启和关窗退出。构建仍有bundle体积提示。

## 已覆盖的行为

| 范围 | 自动化验证重点 |
|---|---|
| 节点与选区 | 重叠／相邻、幂等、字素边界、公式整体选区、Markdown源码复制、标点加粗 |
| 上下文 | 祖先前缀冻结、兄弟排除、附件继承、展示图片和思考摘要排除 |
| 版本与编辑 | 候选采用／拒绝、切版隔离、编辑拆出独立块、下方插块、当前／全部版本删除 |
| 分支与笔记 | 三层DOM选区追问、高亮恢复、原子笔记保存、后续问答、递归删除及资源清理 |
| 流式协议 | SSE拆包与UTF-8、上游请求、reasoning分离、停止／重试、提前断连、完成时无重复正文 |
| 窗口与菜单 | 关闭不停止生成、外部／Esc关闭、共享居中缩放及记忆、堆叠方向、右键和浮动菜单 |
| 模型与设置 | 独立密钥、模型发现、参数过滤、图片能力、昵称／字号／快捷键、确认偏好、全量清空、通用偏好自动保存／离开时提交、慢响应顺序、模型弹窗确认／取消隔离 |

复制选区用例需等待流空闲，不能仅因用户消息已显示就期待追问菜单可用。浏览器测试通过真实DOM Range验证交互，不以直接调用分支API替代选区路径。

## 验证限制

- 模型接入通过本机兼容stub验证，尚未使用真实外部模型完成端到端调用；供应商参数和图片能力需按实际服务验证。
- InkToMd转换已有独立真实服务核查，自动化采用本机stub，不保证外部服务持续可用或论文图片完整。
- 不把现有测试覆盖描述为穷尽所有并发、移动端手势、供应商差异或无障碍行为。
- Cloudflare Pages纯网页、PWA安装、Electron签名及多平台公开发布均未交付。桌面本地打包见[12](12-electron.md)。

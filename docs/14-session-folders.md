# 会话文件夹存储与交互

本方案已获用户确认（2026-11-04），并已实现。文件夹及归属存现有本地SQLite，不写入聊天上下文。

- 新增 folders：id、name、parent_id、position；最多根文件夹＋一级子文件夹，后端校验深度、循环与重名（同级）。
- 新增 session_folders：session_id（唯一，外键级联删除）、folder_id、position；未分配的会话显示在最近对话，按更新时间倒序。
- 最近对话固定按更新时间倒序，不允许手动排序。文件夹及文件夹内会话可拖放排序；会话拖到最近对话即移出文件夹，恢复日期排序，不修改更新时间。
- 删除文件夹仅删除分类，其会话（含子文件夹会话）移回最近对话，不删除聊天内容；弹窗明确提示。
- 展开状态存在浏览器localStorage.expandedFolders，仅影响展示。文件夹区域最多占侧栏列表可用高度50%，超出独立滚动。
- 用CREATE TABLE IF NOT EXISTS初始化这两张独立新表，保留现有数据；全量清除同时删除文件夹。

此方案不修改已有消息／节点存储结构。

## 拖放与删除

- 文件夹行接收会话或文件夹，放入该文件夹；文件夹前方的窄插入区用于同级排序，列表末尾可移到根层末尾。
- 文件夹内会话放在目标会话上方插入，底部空区追加；允许跨文件夹移动。
- 含子文件夹的根文件夹不能放入另一文件夹，否则将产生三级结构；不能移动到自身或后代。重名限制仅同级，接口也执行校验。
- 文件夹重命名不影响会话。删除文件夹级联删除子分类及归属，聊天仍在sessions中；遵循通用删除确认设置。
- 新建／重命名／删除用紧凑弹窗；左侧每项悬停或聚焦提供对应操作。会话仍沿用原重命名／删除流程。
- 文件夹API：GET／POST /folders，PATCH／DELETE /folders/:id，POST /folders/:id/move（parentId、可选beforeId）；POST /sessions/:id/move（folderId、可选beforeId）。null表示根层／移回最近对话。
- 排序操作在事务内更新连续position；归属表一条会话最多一行。重启保留分类，清空所有数据同时清空文件夹。

## 拖动落点引导

仅实际文件夹行显示移入蓝框；会话排序、文件夹排序和末尾追加采用蓝色插入线。最近对话区域不显示蓝框，仍接收拖入并按日期排序。不显示指针旁动态文字、空文件夹“拖入对话”或拖动时的根目录文字提示。

文件夹子内容容器的空白和缩进不作为父文件夹落点，落点只由具体行、排序条或末尾追加区确定，避免嵌套事件冒泡引起目标跳变。会话经过文件夹前的窄排序条时，与文件夹行统一判为移入；文件夹拖动则按同级排序处理。高亮不改变布局尺寸，拖动中隐藏行内操作按钮。

移到自身、超过两级或同级重名等无效目标不高亮，使用禁放指针，释放时前后端仍执行校验。离开列表、移到非落点区域、结束或取消拖动时清除高亮。

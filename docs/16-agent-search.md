# 16 · 联网工具与轻量循环

## 使用与开关

在「设置 → 供应商 → 联网搜索」配置 DeepSeek API Key。配置弹窗必须点击保存，关闭或取消不落盘；清除按钮也在保存后生效。使用 DeepSeek 官方 Search 和 Fetch 服务，直接访问，不经过论文转换代理；对话模型可以来自其他供应商，但必须支持工具调用。

配置后，主对话、分支共用输入框的文件按钮右侧出现「关闭／自动」开关。默认关闭，每个输入框在本页面生命周期内独立记住选择；刷新恢复关闭。模拟模型显示禁用提示。清除搜索密钥后隐藏开关，发送回到关闭模式。笔记编辑不显示开关。

- 关闭：沿用原有单次模型请求，不提供工具、不追加搜索提示词、不进行额外模型推理。
- 自动：AI SDK Core 驱动函数工具循环，模型自行决定是否搜索、是否读取网页，也可以直接回答。自动不等于每次强制搜索。结合追问重新回答沿用目标流输入框的模式及模型。

Search／Fetch 按服务商成功非空请求计费，对话模型调用另计。保存密钥不自动进行收费检测。

## 数据与生命周期

**工具执行记录不持久化，不新增数据库表。** 搜索密钥复用现有 secrets.json 的 searchKey 字段，桌面版沿用 safeStorage 加密，Web 开发预览沿用现有本机密钥机制。模型密钥和搜索密钥互不覆盖，API仅返回provider与configured，不返回密钥。清空数据沿用现有密钥清理流程。

发送模式写入既有 generations.settings_json，任务原始上下文仍是既有 context_json。本轮的工具调用、结果、网页缓存和协议附加数据仅在服务端循环内保留；SSE将执行状态和来源发送到前端当前job。生成结束、停止或失败后，折叠查询过程消失，不保留可再次打开的历史记录。刷新无法恢复或续跑循环。

完成回答会附上工具成功获得的来源链接清单，随正文正常保存、切块和进入后续上下文；模型也被要求在相关论述旁引用真实URL。程序追加的清单包含本轮全部有效来源，可能包括未实际用于结论的来源；它不代表逐句事实核验。停止／失败只保存已输出的正文，不保证补齐来源清单。

后续对话不会再次发送原始搜索摘要、网页全文、工具协议或思考签名；只包含通常路径范围内保存的回答及链接。因此模型不能直接延续上轮工具调用，需要时重新查询。

## 循环与协议

实现入口为 server/providers/agent.ts，使用 AI SDK Core 和三个接口适配器：Chat Completions 使用 openai-compatible，Responses 使用 openai，Messages 使用 anthropic。保留现有模型地址、密钥、参数和图片能力配置。无代理商网关，无MCP、Skill或任意命令入口。

SDK在本轮回传工具请求／结果和必要的思考协议：Chat reasoning_content、Responses encrypted reasoning、Messages signed thinking。Responses始终store=false，显式包含加密思考内容，不依赖服务端会话或previous_response_id。这些数据不进入数据库。

server/web-search.ts提供：

| 工具 | 行为 |
|---|---|
| web_search(query) | POST https://api.deepseek.com/v1/tools/search；查询1–128字符，count=5、need_content=false；最多返回5个公开来源，每条摘要最多2400字符 |
| web_read(url, offset=0) | POST https://api.deepseek.com/v1/tools/fetch；缓存本轮网页，每次交给模型最多10000字符；返回nextOffset及总字符数，按需继续读取 |

来源URL去重并由程序编号。仅允许HTTP(S)公开地址，拒绝凭据、本地名称及私网字面IP；网页读取由DeepSeek执行，不由本机直接下载目标站点。该检查不是DNS解析或完整网络隔离。工具响应最多4MiB，禁止重定向；网页作为不可信资料交给模型，相关提示词独立保存在prompts/context.json。

## 明确限制与错误

- 每轮最多8次模型请求、12次工具执行、总计3分钟；单次搜索／读取最多30秒。无自动重试，不自动换模型或静默降级。
- 每次模型请求在发送前，对包含工具说明及已有结果的最终请求重新估算预算，预留输出空间；同时限制请求体16MiB。估算沿用本项目字符算法及图片估算，不是供应商实际tokenizer。
- 工具失败向模型返回明确错误，同时展示失败状态；不会伪装为空结果。无效工具调用、循环上限、输出上限或模型错误终止本轮并提示，已有正文沿用普通生成收尾。
- 用户停止、页面断连取消当前模型／工具请求；保留已生成正文并切块，后续可继续对话。重构停止不生成候选。
- API形式适配不保证任意兼容供应商都支持工具调用、图片或所有扩展参数；错误提示用户检查工具调用能力及配置。

## 验证边界

使用本机HTTP模拟服务验证三种协议的「搜索 → 读取 → 回答」、思考协议回传、来源保存、后续上下文不含原始工具结果、关闭时单次请求、密钥隔离、预算、上限及取消；无截图浏览器检查配置弹窗及开关。没有读取真实用户配置或调用付费模型／搜索，实际供应商联网结果与费用需实际使用时验证。

## 维护规则

- 用户的最新指令优先；实现发生变化时直接修改对应模块，不在文末追加互相矛盾的旧规则。
- 只把已实现的能力写为当前功能；后续方向和未验证范围明确注明。
- 运行入口为根目录 [README.md](../README.md)，任务续接入口为 [agent.md](../agent.md)。Git 保存修改历史，无需在工程说明中重复维护。
- `research/` 为独立调研资料，不是产品需求或运行依赖。当前产品范围以01为准。
- 项目许可证为 GNU AGPL-3.0-only，完整文本见根目录 [LICENSE](../LICENSE)。
- 界面视觉检查由用户进行；agent 只执行代码、数据和功能检查，不生成或检查界面截图。

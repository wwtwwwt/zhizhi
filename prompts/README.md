# 模型上下文模板

本目录是发送给模型的自然语言模板的唯一维护入口，不在业务代码中维护另一份副本。

- `context.json`：真实／模拟模型共用的请求模板，字段说明与示例见 [模板手册](../docs/11-prompt-templates.md)。
- `fake.json`：模拟服务输出的固定思考摘要，属于调试输出，不是请求上下文。
- 固定模拟正文仍放在 `server/providers/fake.ts`；它是输出样本，不是提示词。

JSON 字符串中的 `\n` 表示换行。动态变量使用 `{{name}}`；只替换一次，不解释插入数据中的占位符，不执行表达式。添加变量时必须同步 `server/prompts.ts` 的调用及测试。

模板由服务端静态导入。开发修改后重启 API 服务生效（watch 环境会重新加载依赖）；Electron 构建会将 JSON 嵌入主进程产物，无需另行复制文件。已创建任务保存的是渲染后的消息，修改模板不会改变该任务。

调整自然语言、标题、包装可直接修改 JSON；调整读取范围、角色、顺序、树遍历或附件类型仍需修改业务代码，不能仅靠提示词实现。浏览器不直接加载这些模板，当前不提供界面编辑或运行时热更新。
